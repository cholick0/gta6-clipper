## The clip

Cut from Rockstar's official GTA VI Trailer 2: the hook is the trailer's action run — a helicopter skimming the Leonida swamp, jet skis racing past the Vice City skyline, and a motorcycle with a plane roaring overhead — cropped vertical (1080×1920) so it posts as a YouTube Short. Then it turns to the viewer: "Make clips like this with AI and earn money on make.fun", with the bounty page on screen.

The clip itself is not in this repository — the video is the entry, and this repo hands in its address in `VIDEO.json`. `main.ts` copies that file to `/output` and does nothing else.
